# PowerShield-FL — Setup Guide

## Prerequisites

- Python 3.10+ (the recorded runs used 3.14.5)
- 4+ GB RAM recommended; quick mode ran on this CPU-only host
- Windows, Linux, or macOS
- No GPU required

## Installation

```bash
cd B:\surya-11
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env   # optional; no API keys are needed
```

Dependencies: NumPy, Pandas, scikit-learn, PyTorch (CPU), Matplotlib, SciPy, PyYAML, psutil, SHAP, Streamlit, Plotly, pytest.

## Dataset Options

### A. Synthetic demo (default, no download)

```bash
python main.py --demo
```

Uses `SYNTHETIC DEMO DATA` generated by `preprocessing/loader.py`. The quick suite uses 240 consumers × 180 days × 48 half-hourly readings. Every output is labelled synthetic.

### B. SGCC

Place the raw SGCC files under `data/raw/` and set:

```yaml
data:
  source: sgcc
  sgcc:
    consumption_file: data.csv
    label_file: label.csv
```

The loader expects the standard SGCC wide matrix plus labels; adjust `config/datasets.yaml` if your copy has different file names. No SGCC data is bundled.

### C. Long CSV

```yaml
data:
  source: long_csv
  long_csv:
    filename: readings.csv
    timestamp_col: timestamp
    consumer_col: consumer_id
    consumption_col: consumption
```

The long CSV must also provide a label source (the loader supports a consumer-level label file/column; inspect `preprocessing/loader.py` before adapting). If labels are absent, the project reports `DATASET NOT CONFIGURED` rather than inventing labels.

## Configuration

`config/config.yaml` holds mode presets and experiment/model settings. Component YAML files hold dataset, client, privacy, aggregation, and sweep settings.

Recorded quick preset:

```yaml
experiment:
  mode: quick
  seed: 42

data:
  synthetic:
    consumers: 240
    days: 180
    theft_rate: 0.15

clients:
  num_clients: 5
  partition_strategy: non_iid
  dirichlet_alpha: 0.5

federated:
  rounds: 8
  local_epochs: 2
  batch_size: 128
  learning_rate: 0.001
  participation_rate: 1.0

privacy:
  enabled: true
  clipping_norm: 1.0
  noise_multiplier: 0.001
  secure_aggregation: false

communication:
  compression: true
  method: quantize
  quant_bits: 8

aggregation:
  method: adaptive

explainability:
  shap_samples: 40
  shap_background: 30
  shap_nsamples: 100
  permutation_repeats: 5
```

Full mode changes the preset to 600 consumers × 365 days, 10 clients, 25 rounds, and seeds `[42, 123, 2026]`; scalability adds 20 clients. **Full mode was not executed on this host.**

Any value can be overridden without editing YAML:

```bash
python main.py --mode quick --override federated.rounds=4
python main.py --demo --override privacy.enabled=false
python main.py --demo --override communication.method=topk_quantize
```

## Running the Dashboard

```bash
streamlit run dashboard/app.py
```

Open http://localhost:8501.

The dashboard reads only `results/metrics/summary.json`, per-run artifacts, and the saved checkpoint. Without results it prints:

```text
No experimental result available. Run the experiment first.
```

If a checkpoint is missing/corrupt, detection shows an error rather than a fabricated prediction. The recorded validation used Streamlit `AppTest` (10 tabs, no exceptions) and a live headless server health check on port `8511` (HTTP `200`, body `ok`).

## Troubleshooting

### Low-memory warning

The environment check warns if available RAM is below the configured threshold. For a smaller demo:

```bash
python main.py --demo --override data.synthetic.consumers=80 --override data.synthetic.days=60
```

### SHAP failure

SHAP is reported as `PARTIAL`/`EXPERIMENT FAILED` in `explainability_status.json` if it fails; permutation importance and local gradient×input explanations still run. The dashboard reads the status instead of hiding the failure. The implementation uses KernelExplainer because DeepExplainer was unreliable with the installed SHAP/PyTorch versions.

### Stage failure

Look for `EXPERIMENT FAILED` in `results/metrics/summary.json` or the console. The traceback is stored in the stage entry. Do not edit metrics manually; fix the code/config and re-run.

### Slow training

Reduce `federated.rounds`, `data.synthetic.consumers`, or use `--demo`. Record the changed configuration; quick-mode reductions change the experiment methodology.

### Missing packages

```bash
pip install -r requirements.txt
```
