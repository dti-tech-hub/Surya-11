# Data Directory

Layout:

- `raw/` — original datasets (never modified)
- `processed/` — cached preprocessed artifacts (regenerated by the pipeline)
- `partitions/` — saved client partitions (regenerate via `scripts/create_clients.py`)

## Default dataset

With no files present, PowerShield-FL generates **SYNTHETIC DEMO DATA** via
`preprocessing/loader.py` (configurable in `config/datasets.yaml`). All outputs
derived from it are labelled `SYNTHETIC DEMO DATA`.

## Adding a real dataset

### SGCC (State Grid Corporation of China) electricity theft dataset

Place in `data/raw/`:

- `data.csv` — rows = consumers (`CONS_NO` column), columns = 48 daily half-hour
  readings over ~1 year (or any wide daily-consumption layout)
- `label.csv` — `CONS_NO` + `FLAG` (1 = theft, 0 = normal)

Set `data.source: sgcc` in `config/datasets.yaml` (or `auto`, which prefers
real data when present).

### Long-format CSV

Place `data/raw/readings.csv` with columns `timestamp`, `consumer_id`,
`consumption` and an optional `label` column; set `data.source: long_csv`.
